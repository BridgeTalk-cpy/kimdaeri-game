# 김대리의 한 달 — 업무관리 시뮬레이션

## 주소
- 참가자: `https://(버셀 주소)/`
- 강사: `https://(버셀 주소)/host` (비밀번호: `js/config.js`의 HOST_PIN, 기본 1105)
- 리허설(인터넷 없이 같은 브라우저에서만): 주소 끝에 `?demo`

## 강사 화면 사용법
1. 상단 **다음 ▶** 버튼으로 단계를 넘깁니다: 대기실 → R1 진행 → R1 마감·설명 → R2 … → 마무리
2. **마감**을 누르면 그 시점까지의 응답으로 결과 탭이 열립니다. 장면 버튼(1, 2, 3…)으로 넘기세요.
3. **가상 70명 리허설**: 실제 응답 없이 결과 화면을 미리 볼 수 있습니다. 교육 전에 꼭 끄세요.
4. **결과 내려받기**: 실제 참가자 응답을 엑셀(CSV)로 저장합니다.
5. **새 세션**: 응답을 비우고 처음부터 시작합니다(두 번 클릭). 이전 응답은 파이어베이스에 남아 있습니다.

## 문구 수정
게임 속 모든 문구는 `js/content.js`에 있습니다.
